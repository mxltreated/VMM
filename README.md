# Vintage Mod Manager (VMM)

A fast, lightweight desktop mod manager, modpack sharer, and multiplayer launcher built for **Vintage Story**. Manage your mods, share modpacks with friends, and host co-op sessions—all from one clean app.

---

## ✨ Key Features

### 📦 Mod Management & Mod DB Browser
- **Enable / Disable Without Deleting**: Cleanly toggle installed mods on or off without losing your files.
- **Built-in Mod DB Browser**: Search `mods.vintagestory.at`, filter by category tags and game version, read full mod descriptions in a clean reader view, and install any release in one click.
- **Update Checker & Changelogs**: Check all installed mods for updates and preview release changelogs before you update.
- **In-App Config Editor**: Quickly tweak JSON files in your `ModConfig` folder before launching the game.

### 🗂️ Profiles & Easy Modpack Sharing
- **Multiple Mod Profiles**: Switch between different mod setups (e.g., Vanilla+, Hardcore, Server Pack) without duplicating your `.zip` mod files.
- **Per-Profile Settings**: Customize launch arguments, RAM limits, or pin specific mod versions per profile.
- **Share & Import Modpacks**:
  - Export as a lightweight `.vmmpack.json`, a full `.vmmpack.zip` (with your `ModConfig` files included), or a compact `vmm1:...` share code.
  - Import from a file, share code, or a GitHub / URL link—complete with one-click **Sync** when a friend updates their pack.

### 🌐 Multiplayer & Zero-Setup P2P Rooms
- **Built-in Encrypted P2P Tunnel**: Host or join multiplayer sessions using a simple `vmm-p2p:...` Room Code. No router port-forwarding, VPNs (Hamachi/Radmin), or extra downloads required.
- **Works with Open to LAN & Dedicated Servers**: Share your singleplayer world over "Open to LAN", or spin up a dedicated server using VMM's built-in server manager with live console logs and editable server settings.

### 🔄 Hassle-Free App Updates
- Automatically checks for new VMM releases and lets you update and restart directly inside the app.

---

## 🚀 Quick Start
1. **Download & Run** the installer or standalone `.exe`.
2. **Verify Paths**: VMM auto-detects your Vintage Story installation and `VintagestoryData` folder on first launch (you can adjust them anytime in **Settings**).
3. **Browse & Play**: Enable or install mods, pick a profile, and hit **Launch Vintage Story**!
